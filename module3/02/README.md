# Module 3 task 02

## Мини командный интерпретатор

Программа выводит приглашение, читает имя программы и аргументы, запускает ее
через отдельный процесс и после завершения снова показывает приглашение.

Поддерживаются системные программы и программы из текущего каталога.

Сборка:

```bash
make
```

Запуск:

```bash
./mini_shell
```

Примеры команд внутри интерпретатора:

```bash
ls
cd ..
pwd
sum_args 10 20 3.5
join_args hello from shell
max_value 4 18 2 7
exit
```

Команда `cd` сделана как встроенная команда, потому что смена каталога должна
происходить в самом процессе интерпретатора.

Очистка:

```bash
make clean
```
