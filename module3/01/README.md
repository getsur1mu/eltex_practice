# Module 3 task 01

## Обработка аргументов родителем и дочерним процессом

Программа принимает аргументы командной строки. Если аргумент является числом,
то выводит его и значение, умноженное на 2. Если аргумент не число, он выводится
как обычная строка.

Аргументы делятся между родительским и дочерним процессом примерно поровну.

Сборка:

```bash
make
```

Запуск:

```bash
./arguments 10 text 3.14 hello -7
```

Очистка:

```bash
make clean
```
