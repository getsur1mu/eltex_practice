# Module 3 task 03

## Телефонная книга с хранением в файле

Основа похожа на телефонную книгу из модуля 2, но контакты сохраняются в файл
`contacts.dat`. При запуске программа читает файл, при выходе записывает туда
текущий список.

Для работы с файлом используется небуферизованный ввод-вывод:
`open`, `read`, `write`, `close`. Данные читаются и записываются блоками по
размеру структуры `Person`.

Сборка:

```bash
make
```

Запуск:

```bash
./phonebook_file
```

Очистка:

```bash
make clean
```
