# Module 2 task 2.2

## Простой калькулятор.

```text
 _____________________
|  _________________  |
| | AA           0. | |
| |_________________| |
|  ___ ___ ___   ___  |
| | 7 | 8 | 9 | | + | |
| |___|___|___| |___| |
| | 4 | 5 | 6 | | - | |
| |___|___|___| |___| |
| | 1 | 2 | 3 | | x | |
| |___|___|___| |___| |
| | . | 0 | = | | / | |
| |___|___|___| |___| |
|_____________________|
```

Сборка и запуск:

```bash
make
```

Отдельно собрать:

```bash
make calculator
```

Очистка:

```bash
make clean
```
