# Module 2 task 4.1

## Телефонная книга на двухсвязном упорядоченном списке.

```text
      __...--~~~~~-._   _.-~~~~~--...__
    //               `V'               \\ 
   //                 |                 \\ 
  //__...--~~~~~~-._  |  _.-~~~~~~--...__\\ 
 //__.....----~~~~._\ | /_.~~~~----.....__\\
====================\\|//====================
                dwb `---`

```
Сборка и запуск:

```bash
make
```

Отдельно собрать:

```bash
make phonebook_list
```

Очистка:

```bash
make clean
```
