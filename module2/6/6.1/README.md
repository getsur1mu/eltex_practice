# Module 2 task 6.1

## Телефонная книга со статической библиотекой.

```text
(\ 
\'\ 
 \'\     __________  
 / '|   ()_________)
 \ '/    \ ~~~~~~~~ \
   \       \ ~~~~~~   \
   ==).      \__________\
  (__)       ()__________)

```

Сборка и запуск:

```bash
make
```

Отдельно собрать:

```bash
make phonebook_static
```

Очистка:

```bash
make clean
```
