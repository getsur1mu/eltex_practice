# Module 2 task 6.2

## Телефонная книга с динамической библиотекой.

```text
                  .----.
      .---------. | == |
      |.-"""""-.| |----|
      ||       || | == |
      ||       || |----|
      |'-.....-'| |::::|
      `"")---(""` |___.|
     /:::::::::::\" _  "
    /:::=======:::\`\`\
    `"""""""""""""`  '-'

```

Сборка и запуск:

```bash
make
```

Отдельно собрать:

```bash
make phonebook_dynamic
```

Очистка:

```bash
make clean
```
