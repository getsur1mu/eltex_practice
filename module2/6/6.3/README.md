# Module 2 task 6.3

## Калькулятор с операциями из динамических библиотек.

```text
 _____________________
|  _________________  |
| | AA  3.141592654 | |
| |_________________| |
|  __ __ __ __ __ __  |
| |__|__|__|__|__|__| |
| |__|__|__|__|__|__| |
| |__|__|__|__|__|__| |
| |__|__|__|__|__|__| |
| |__|__|__|__|__|__| |
| |__|__|__|__|__|__| |
|  ___ ___ ___   ___  |
| | 7 | 8 | 9 | | + | |
| |___|___|___| |___| |
| | 4 | 5 | 6 | | - | |
| |___|___|___| |___| |
| | 1 | 2 | 3 | | x | |
| |___|___|___| |___| |
| | . | 0 | = | | / | |
| |___|___|___| |___| |
|_____________________|

```

Сборка и запуск:

```bash
make
```

Отдельно собрать:

```bash
make calculator_dynamic
make plugins/add.so plugins/sub.so plugins/mul.so plugins/div.so plugins/exp.so
```

Запуск с каталогом библиотек:

```bash
./calculator_dynamic plugins
```

Очистка:

```bash
make clean
```
